I created an Android mobile game called **Times Table Grid Game**, designed to teach multiplication tables in a new and fun way. I have maintained the game on Google Play Store since 2012, and it has accumulated over 100,000 downloads. 

![All Downloads](/assets/2025/07/all_downloads_eng.jpg)
![All Ratings](/assets/2025/07/all_ratings.jpg)

## Game Description

This isn't an ordinary times table game. This is something new! In this game you are asked to place the product of a multiplication in the correct cell in the grid. The better you play, the harder levels you will face. Easy to learn, difficult to master! An evident challenge for all of us, and suitable for all ages.

Everybody knows how to calculate 3 x 3 or 7 x 4. What if you were asked to calculate which two numbers need to be multiplied in order to yield the products 9 or 28? It isn't as simple as you might think.

This game combines fun and benefit. Scientific research has proven that daily brain exercises are good for your health, and what would be a better way to do your daily brain exercises than with a couple of fun multiplication calculations.

- A unique and brand new way to do multiplication calculations
- Several different difficulty levels
- High Scores
- Instructions
- A fun times table game suitable for all ages

## How to Play

The game presents you with a grid where you need to place multiplication results in the correct positions. As you progress, the difficulty increases, making it both educational and challenging.

For Android users, you can download the game from Google Play:
[https://play.google.com/store/apps/details?id=com.soivi.timestablegridgame](https://play.google.com/store/apps/details?id=com.soivi.timestablegridgame)

If you don't have Android, or for some other reason don't want to install the game from Google Play, you can also try the game from this site:
[https://timestablegridgame.soivi.net/](https://timestablegridgame.soivi.net)

You can also download the game to your computer for testing. Download the repository to your local machine and double-click the `index.html` file to open the game in your browser where you can play it.

You can see the first version of the game in action in this YouTube video: [https://www.youtube.com/shorts/vPy6wlTE-jI](https://www.youtube.com/shorts/vPy6wlTE-jI)

## Technical specs

The game uses HTML, JavaScript and LocalStorage. It is created as a PWA (Progressive Web Application).

When I launched the game, it was built using HTML, JavaScript, WebSQL database and Apache Cordova (formerly PhoneGap).

You can find the source code from here:
[https://github.com/Soivi/TimesTableGridGame](https://github.com/Soivi/TimesTableGridGame)
